Гражданам каких стран нужна виза для посещения Мексики? — Паспорт и визы

Хотя мексиканцы способны ездить с одним лишь паспортом без виз в 149 стран мира, безвизовый режим Мексики с другими странами не всегда взаимный. Гражданам 130 страны мира для посещения Мексики необходима виза, и ее разрешается получить только в одном из 130 консульских учреждений державы за рубежом.

Виза в Мексику нужна

Если ваша государство есть в этом списке, вам необходимо обрести визу Мексики независимо от того, каким видом транспорта вы собираетесь попасть в страну. Исключение: граждане Украины, России и Турции способны попасть в Мексику без визы, но только на самолете, оформив безвозмездное электронное разрешение.

Державы, гражданам которых для посещения Мексики нужна виза, на карте обозначены серым цветом.

С 2021 года гражданам Венесуэлы для посещения Мексики виза не нужна.

Стандартная виза в Мексику открывается для поездок с любой целью, не предполагающей коммерческой деятельности, со сроком пребывания в стране до 180 дней. Срок пребывания обновляется после выезда и повторного въезда в страну.

Как приобрести консульскую визу для посещения Мексики, мы писали в этой статье. Порядок приобретения визы Мексики одинаков для граждан всех стран мира, за редким исключением.

Одно из немногих исключений из визового режима предусмотрено для граждан Украины, России и Турции. Хотя формально для въезда в Мексику им необходима виза, можно составить без оплатые электронное разрешение по Интернету, распечатать и предъявить на паспортном контроле. Электронное разрешение действительно только для въезда в Мексику по воздуху.

С другой стороны, для граждан отдельных стран, скажем, Индии и Китая, порядок приобретения мексиканской визы выглядит более сложным. Это связано с более высоким требованием к документам, подаваемым при получении визы Мексики.

И, наконец, если согласно списка стран виза в Мексику вам нужна, но у вас есть один из следующих бумаг, то для въезда в Мексику вы можете использовать его:

  • Многократная действующая виза:
    • США
    • Канады
    • одной из стран Шенгенской зоны
    • Великобритании
    • Японии
  • Постоянный (не временный) статус резидента в:
    • США
    • Канаде
    • одной из стран Шенгенской зоны
    • Великобритании
    • Японии
    • Чили
    • Колумбии
    • Перу
